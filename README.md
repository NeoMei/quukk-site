# quukk 公司主页

中文响应式公司主页，以五款应用平台和两款支撑平台为基础。纯 HTML、CSS、JavaScript，无构建依赖。

## 本地查看

在本目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173/ 。正式部署目录为 `dist/`。资源路径相对网站根目录，因此请通过 HTTP 服务器打开。

## 文件

- `dist/index.html`：公司介绍、七款产品与联系入口。
- `dist/styles.css`：基础响应式样式。
- `dist/hero-refresh.css`、`dist/product-shots.css`：新版产品展台首屏、全宽截图、大图查看器。
- `dist/app.js`：移动导航、产品推荐、键盘导航、截图放大和虾说视图切换。
- `dist/assets/`：产品品牌图标、定稿 Logo 和产品界面截图。
- `design/`：生成的视觉概念及设计验收说明，不随静态站点部署。
- `.openai/hosting.json`：Sites 站点标识与静态部署配置。

站点默认按 Sites 的仅所有者可见方式部署。未绑定 quukk.com，未修改既有产品站点或 DNS。

## 界面素材

品牌标志沿用定稿的暖色 Q(ai)。首屏以两款产品界面和放大的 Q 形底纹构成展台，五款应用提供快速入口。此前生成的 Q 雕塑素材保留在资产中。

- **SuperWagie**：用当前产品真实工作台组件在隔离环境渲染中文演示数据并截图，图注明确“演示数据”。未读取用户工作文件或调用生产接口。
- **AgentWiki**：产品仓库已有的真实知识库阅读验收截图，内容为通用“页面管理”说明，账户为“设计验收”，并非最新版本验收声明。
- **璇玑**：用户提供的真实工作流编辑器截图，仅保留编辑器区域，去掉浏览器和工作空间侧栏。节点离线状态原样保留，不表示工作流执行成功。
- **灵犀**：依据用户登录后的真实三栏界面制作静态界面示例，按用户要求加入通用文档、问答引用和内容生成示例。图内、图注及大图标题均标注示例；不是生产模型运行结果。
- **虾说**：默认使用用户切换账号后提供的真实智能体会话界面，截取时避开顶部账号栏。可切换到按真实布局制作的多角色讨论示例，明确标注“界面示例”。未提交讨论话题或发起真实模型调用。

示例源文件与素材说明见 `design/product-refresh/`，不随静态站点部署。只有 `dist/` 的审阅后图片被部署。

## 交互与检查

- 七款产品入口与外链安全属性：五款应用独立展示、两款支撑平台在应用场景之后单独介绍。
- 四个应用场景，支持鼠标、触摸、方向键、Home/End。
- 五款应用截图均支持大图查看；Escape/关闭按钮恢复焦点，手机可横向滚动查看完整细节。
- 虾说实际界面与讨论示例可切换，放大图片及图注同步更新。
- 手机菜单展开、点击跳转后收起、Escape 关闭。
- 1440、768、390 像素完整页面截图检查；IAB 实测交互与 390 像素无横向溢出。
- 璇玑工作流的桌面、手机浏览器验收见 `design/warm/xuanji-review.md`。
- 无后端表单、无跟踪代码、无第三方脚本运行时依赖。

当前首屏与截图展示验收见 `design/product-refresh/REVIEW.md`；此前暖色设计见 `design/warm/REVIEW.md`，Logo 说明见 `design/brand/README.md`。`dist/brand.html` 提供标志预览及 SVG 下载。

## 产品层级

依据用户最新定位，SuperWagie、AgentWiki、璇玑、灵犀知识库、虾说为五款重点应用，均使用独立图文展示与同等标题层级。UniHub、LLMRouter归入支撑平台，置于场景之后，使用简明开放目录。主导航分别提供应用平台、应用场景、支撑平台入口。场景推荐只呈现应用平台，未把账户或模型服务混入应用推荐；不承诺跨产品自动集成。
