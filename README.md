# quukk 公司主页

中英文双语响应式公司主页，以五款应用平台和两款支撑平台为基础。纯 HTML、CSS、JavaScript，无构建依赖。

## 本地查看

在本目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173/ 。正式部署目录为 `dist/`。资源路径相对网站根目录，因此请通过 HTTP 服务器打开。

## 文件

- `dist/index.html`：公司介绍、七款产品与联系入口。
- `dist/en/index.html`：完整英文首页，独立静态页面。
- `dist/language.js`、`dist/language.css`：语言切换、偏好记忆、章节位置保留及英文排版。
- `dist/styles.css`：基础响应式样式。
- `dist/hero-refresh.css`、`dist/product-shots.css`：新版产品展台首屏、能力说明与使用示例、辅助截图和大图查看器。
- `dist/app.js`：移动导航、产品推荐、键盘导航、截图放大和虾说视图切换。
- `dist/assets/`：产品品牌图标、定稿 Logo 和产品界面截图。
- `design/`：生成的视觉概念及设计验收说明，不随静态站点部署。
- `.openai/hosting.json`：Sites 站点标识与静态部署配置。

正式官网为 **https://www.quukk.com/**，2026-10-25 部署至 113.249.120.24，沿用 47.108.85.222 的现有入口转发和 DNS。部署、验收与回滚记录见 `deploy/README.md`。此前的 Sites 站点仍保留为仅所有者可见的预览。

## 中英文版本

中文入口 `/`，英文入口 `/en/`；品牌页分别为 `/brand.html` 与 `/en/brand.html`。顶部的“中文 / EN”是真实链接，切换后保留当前章节，正常浏览器会记住显式选择。初次访问默认中文；选择英文后再次访问根入口会进入英文版；直接打开 `/en/` 始终显示英文。存储不可用时仍可切换，必要时通过 `?lang=zh` 或 `?lang=en` 指定语言。

两套页面均直接包含完整内容，关闭 JavaScript 后仍可阅读及使用语言链接。导航、产品说明、场景推荐、截图弹窗、联系入口、无障碍标签及页面元数据均有对应语言；真实产品截图保留原界面，英文图注明确界面语言和演示素材性质。每页配置自己的 canonical 和对应 hreflang。

在 IAB 中验证了双向切换、根入口偏好恢复、中文切回后刷新、章节锚点保留、英文菜单和场景切换、讨论示例及截图弹窗、品牌页切换；英文 320/390/768/1024/1440 像素无水平溢出。另校验了语言脚本在受限存储、显式 URL、普通偏好等 8 个导航情形。

## 产品介绍层级（2026-10-25 更新）

五款应用以核心价值、三项能力说明和一个明确标注的使用示例为阅读主线，截图作为辅助材料。桌面采用文字与截图并排、相邻产品交错的版式；平板与手机依次呈现能力、示例、截图。保留原暖色品牌、留白、产品链接和截图来源说明，使用示例不表示已执行的产品任务。

中英文各新增 15 条能力说明、5 个使用示例。1440/768/390/320 像素均无水平溢出；实测虾说视图切换、大图打开与 Escape 关闭、语言切换保留产品锚点。放大按钮及截图切换按钮具有至少 44px 的触控高度。正式站点内容与本地静态发布文件逐字节校验。

## 界面素材

品牌标志沿用定稿的暖色 Q(ai)。首屏以两款产品界面和放大的 Q 形底纹构成展台，五款应用提供快速入口。此前生成的 Q 雕塑素材保留在资产中。

- **犇马 SuperWagie**：用当前产品真实工作台组件在隔离环境渲染中文演示数据并截图，图注明确“演示数据”。未读取用户工作文件或调用生产接口。
- **天枢 AgentWiki**：产品仓库已有的真实知识库阅读验收截图，内容为通用“页面管理”说明，账户为“设计验收”，并非最新版本验收声明。
- **璇玑 XuanGene**：用户提供的真实工作流编辑器截图，仅保留编辑器区域，去掉浏览器和工作空间侧栏。节点离线状态原样保留，不表示工作流执行成功。
- **灵犀**：依据用户登录后的真实三栏界面制作静态界面示例，按用户要求加入通用文档、问答引用和内容生成示例。图内、图注及大图标题均标注示例；不是生产模型运行结果。
- **虾说 ClawMessenger**：默认使用用户切换账号后提供的真实智能体会话界面，截取时避开顶部账号栏。可切换到按真实布局制作的多角色讨论示例，明确标注“界面示例”。未提交讨论话题或发起真实模型调用。

示例源文件与素材说明见 `design/product-refresh/`，不随静态站点部署。只有 `dist/` 的审阅后图片被部署。
