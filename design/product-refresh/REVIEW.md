# 产品界面展示改版 · 2026-10-25

用户要求首屏更有层次、产品介绍使用界面截图；进一步授权为空白产品界面填写示例内容。保持暖色、宽松留白、已定稿 Q(ai) Logo 和五应用＋两支撑的层级。

## 设计

以 quukk 的 Q 形作为产品展台背景，品牌主张与产品定位并列；SuperWagie、璇玑窗口前后排列，底部直接进入五款应用。每款产品采用说明在上、全宽界面在下的结构，避免把界面缩进狭窄卡片。

灵犀根据实际界面构建文档问答示例。虾说默认展示实际智能体会话，并可切换到多角色讨论示例。示例图都有明确标签。原 Logo 几何未改变。

## 素材与边界

见 README 的界面素材说明。真实登录界面的原始参考截图和用户浏览器截图未随部署保留；最终图片去掉账号/浏览器区域。仅展示界面，不声称进行了生产端到端功能验证。

SuperWagie 隔离演示使用真实产品组件。灵犀和虾说的静态示例保持原界面的布局、配色与已知功能，演示对话不是运行记录。所有示例文件只用于生成展示图。

## 验证

- 1440、768、390 宽度的首屏与关键产品展示人工检查。
- 手机宽度无横向页面溢出；大图内部可滚动查看细节。
- 菜单跳转、截图打开与关闭、Escape 和焦点恢复通过浏览器验证。
- 虾说截图切换同时更新图注、大图来源和标题。
- 五应用顺序、两支撑分区、外链、锚点、ARIA 与资源完整性检查。
- JS 语法检查通过。

保留用户明确的米白与暖棕品牌色，优先于通用风格技能对配色的默认建议。通过 CUA 执行视觉检查，未使用另一个自动浏览器运行技能检测脚本。
