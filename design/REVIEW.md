# 设计与验收记录

## 方向

The well-kept board，seed 1447735114。七款 quukk 产品成为一张可进入、可按工作需求选择的产品板。黑白/鲜绿，中文优先；品牌图标保留原色。没有真实团队照片和产品录像，采用代码原生的知识/路由示意与工作示意，不使用无关图库图片。

视觉概念由内置 Image Gen 生成，保存在 hero-concept.png、products-concept.png、directory-concept.png。这是本次实现采用的设计方向，未声称用户逐图确认。

生成提示共同要求：quukk 中文 AI 公司主页；白色 #ffffff、灰白 #f4f5f2、近黑 #171c18、鲜绿 #c4f564；大字、非对称产品板、真实七款产品名称；无虚构指标、无渐变、无阴影；所有操作与文本用 HTML 实现。三份提示分别覆盖首屏、主要产品、产品目录与关于/页脚。

## 概念到实现

| 核验点 | 实现与理由 |
| --- | --- |
| 信息层级 | 保留“让智能，成为生产力。”首屏与探索产品按钮；所有七款均可访问。 |
| 布局 | 保留左文案、右三产品板；主要产品展示、目录、关于与大字页脚。补充应用场景选择器兑现导航“应用场景”。 |
| 色彩 | 平面黑白/鲜绿；去除生成图偶发渐变、阴影、发丝线。 |
| 字体 | 中文无衬线、标题两行以内；桌面首屏 82px（1440宽），手机约42px（390宽）。 |
| 文案 | 以已核验事实替换生成图中错误的 UniHub/璇玑/虾说描述；没有人数、客户数、模型数等假统计。 |
| 示意 | 生成图中的灰条界面改为有意义的任务文字，明确标注工作场景示意。按钮切换只改变示意文本。 |
| 导航 | 一套固定导航“产品/应用场景/关于我们”；不采用后续概念图自行添加的“加入我们/搜索”。 |
| 手机 | 独立菜单、堆叠主要产品、双列场景按钮；390px 无水平溢出。 |
| 细节 | SVG 箭头与勾选，官方产品标志，焦点样式、减少动态效果、外链安全属性。 |

以上是有意修正生成图或补全交互的差异；没有将生成图本身当作可点击网站发布。可见首屏文案差异已逐项核对，新增内容仅有品牌句号、准确的产品短句及示意说明。

## 实际检查

- Node 语法检查通过，静态 HTTP 200。
- 内置浏览器实测导航锚点、管理知识/团队协作/构建 AI 应用推荐切换、方向键切换、代码开发示意切换。
- 390×844 内置浏览器实测菜单展开与点击导航后收起；资源无破图；documentWidth = viewportWidth = 390。
- 专用设计检查器使用本机 Chrome 输出 1440×900、768×1024、390×844 首屏和全页拼接截图，逐张用 view_image 检查；同时用 view_image 对照三张设计概念。
- 原始检查器的 eyebrow 判定把“探索产品”按钮和前一产品里的“工作场景示意”误判为下个标题的眉题；icon-cards 判定把手机产品目录行误判为特性卡片。这两项按截图复核并列为例外。
- few-pictures 的四张照片要求不适用于本页：提供的是软件产品入口，无真实摄影资产；保留诚实的代码示意，不为凑数量加入无关照片。该项明确列为设计例外，不能将检查器的配置通过理解为满足四张照片。
- size-count / no-footage / name-only-title / small-text 为保留警告：响应式字号与品牌大字增加尺寸数；无可用产品视频；中文首屏已明确说明 AI 产品；界面缩略示意中的小字不承载操作必需信息。
- 公开产品功能仅核验文案/发布资源，不等同于实际登录验收。

Top three problems and fixes:

2. 手机场景示意说明竖排且过小：改为13px横排，保留清楚的示意标注。
3. UI 勾选使用字符：改为 SVG，消除表情符号渲染差异。

本轮检查未见内容截断、遮挡、破图或横向溢出。品牌主色、信息顺序、首屏比例与概念保持一致；没有声称未经确认的10/10像素一致。
