# 首页「智能组织」承接 — 评审预览（2026-11-12，第 10 版）

## 这一版的前提

用户定调：不强调概念出自谁，只因为「智能组织」与 quukk 已有的工具链思路一致，所以接受这个概念，
并通过产品组合让它在组织里真正落地。因此这一版**不提人名、不提大会、不引用演讲内容**，
也不复述「新电能 / 新厂房」的比喻。页面上不署名、不标出处，把它当作 quukk 自己的产品主张来讲。

第 3 版按用户提供的《企业 AI 化转型的工具集》示意图调整产品职能：
犇马是任务执行者，天枢是人与人、人与 agent、agent 与 agent 交换信息和沉淀知识的平台，
璇玑是协作流程调度引擎，虾说是智能组织之间以及两个各带 agent 的个人之间的通信工具，
灵犀是组织公共资料库，归一与万流提供统一的 token、计费与权限管理。

第 4 版按两条反馈收敛：

1. 虾说只是辅助工具，核心是犇马、天枢、璇玑、灵犀四款，图上不应让虾说占据中心。
2. 示意图要呈现「智能组织的形态」，把工具嵌进组织里，而不是再罗列一遍产品。

第 5 版按第三条反馈，把示意图从「文字节点」改成**手绘式图示**：

- 小人 = 人，机器人 = agent；一群小人和机器人 = 部门
- 犇马 = 干活的图示（榔头 + 尺）
- 璇玑 = 组织协作流程图（计划 → 分派 → 执行 → 审核 → 归档，含返工回路）
- 天枢 = 知识图谱（中心节点 + 六个知识节点）
- 灵犀 = 资料库（三层书架与文件盒）
- 归一 / 万流 = 钥匙、硬币、仪表（权限、计费、额度）
- 虾说 = 对话气泡，连到「另一个智能组织」

第 6 版按第六条反馈，改用**文生图**绘制插图，并把虾说重新定位：

- 犇马：一头穿围裙、出汗的牛，身前堆满文档，一手笔一手章
- 天枢：知识图谱，含多份 Markdown 文档节点
- 灵犀：装满文档盒与文件夹的书架
- 混编：三位成员与三个机器人并排，示意部门内人与 agent 混编
- 三个部门另配了各自的场景插图（写作、评审、对外交付）
- 虾说不再是「辅助」，而是**两个被 agent 赋能的超级个体之间的沟通工具**，也可以发生在两个智能组织之间；它不是组织内部的执行工具
- 产品 logo 用官方素材精确排版，不交给图像模型画，避免品牌标志被画歪
第 10 版：

- 璇玑流程图重画为真正的流程图：五个圆角节点加实线箭头，审核到执行的返工画成虚线回环（带箭头），窄屏改为竖排流程、回路走右侧。
- 修复全局样式冲突：styles.css 里的 svg 选择器（宽高 24px、fill none）曾把整张流程图压成 24 像素并把文字变透明，现以 .orgshape .xflow-svg 覆盖。
- 犇马形象改用文生图绘制：橙色剪影风格的牛，低头用力、头冒汗、握笔按纸、身前堆稿，与官方 logo 同一套造型语言；去底裁切后作为透明 PNG 使用。
- 虾说英文名改为 AgentBB（中文仍为虾说），域名 clawmessenger.quukk.com 保留。
第 9 版按三条反馈继续细化：

- 审核返回改成**画出来的回环**：虚线从「审核」下沿折回「执行」下方并以箭头指入，不再用一句说明文字；读屏用 sr-only 保留「审核不通过时，流程回到执行」。
- 犇马不再手绘牛头，直接使用 SuperWagie 官方 logo，外框浅底卡片加两颗汗滴点缀，表示「在干活、在出汗」。
- 天枢的知识图谱重画：七个外围节点放大，其中五个画成带折角的 Markdown 文档（含文字线条），另有标签节点与圆形节点，并补了外围互连，中心节点加双环。
- 灵犀的书架重画：三层书架，分别放档案盒、装订册、文件夹与标签盒，加入书脊斜放的册子，格子里的隔断与标签都画了出来。
- 底座改为整行：左侧一句说明，右侧两张卡片（归一 / 万流），各带图标、logo、一行定位与一段职责说明，不再挤成一行脚注。
第 8 版解决图里文字发糊的问题：

- 起因：上一版把说明文字一并画进 SVG，再整体缩放显示，浏览器栅格化后小字发黑、发毛。
- 试过让图像模型整图重绘：密集中文会被画成空白块或乱码，产品 logo 也会变形，不采用。
- 现在的做法：图示 = 真实 HTML 文本 + 内联矢量图标 + 官方 logo 位图；文字走页面字体，任何缩放都清晰；图标做成可复用的 symbol 雪碧图，颜色继承文字色。
- 图内信息也补齐：流程五步各有一句副说明；三个部门各有 3 到 4 个人形与 2 到 3 个机器人图标；天枢是知识图谱（外围为 Markdown 文档），灵犀是四层书架；底座含钥匙、硬币、量表三个图标。
- 虾说收成一条横向卡片，两个智人 A/B 对置，中间是对话气泡与「讨论 · 对齐」。
第 7 版按第七条反馈回到图标化图示，并新增术语：

- 放弃用文生图整张重绘：整图重绘会把文字变成空白块、产品 logo 画歪。改为 SVG 手绘图标 + 官方 logo 内嵌。
- 图示中的每个部件都画成图标：璇玑是流程图（计划-分派-执行-审核-归档，带返工回环）、三个部门是人形与机器人图标并排加一头出汗的牛与公文堆、天枢是知识图谱（外围节点为 Markdown 文档）、灵犀是四层书架、归一与万流用钥匙/硬币/量表表示。
- 虾说不再叫辅助，改称智人与智人的沟通工具。
- 新增术语解释：智人 Agentor 与智能组织 AgentOrg，位于本节开头，两栏对照。
- 图示须内联进页面：以 img 标签引用的 SVG 不会加载外部 image 元素，logo 会变成空白方块。桌面与手机两版 SVG 均内联，marker id 加后缀避免冲突。

## 核心判断

原主页把五款产品按目录并列陈列（产品区 4611px，占整页 7780px 的六成），读者知道有什么，但看不出它们为什么是一套。
「智能组织」的落点不在再多一句口号，而在**先把组织的形态讲出来，再让工具落在它的接缝上**：
人不再按岗位排列，而是和 agent 编成小队；小队之间需要调度、交换、取用资料，工具就长在这些位置上。
所以改动的重心是 show 而不是 tell。

## 形态图示的结构

| 层 | 内容 |
| --- | --- |
| 组织主体 | 一个智能组织内，三个「人 + agent」混编部门（内容与品牌 / 产品与工程 / 运营与客户），各有场景插图；另有一条混编示意图（三位成员 + 三个机器人） |
| 调度 | 璇玑排在部门之上，是一张流程条：计划 → 分派 → 执行 → 审核 → 归档，标注「审核不通过则返工」 |
| 执行 | 犇马不在单独一层：它出现在每个部门里（写作、评审、交付三张场景插图），表示执行发生在部门内部 |
| 交换 | 天枢以知识图谱出现：中心节点连向多份 Markdown 文档节点，示意信息交换后沉淀为可追溯的知识条目 |
| 资料 | 灵犀画成资料库：四层书架，装满文档盒、文件夹与装订册 |
| 底座 | 归一（账号与权限）与万流（模型与 token），横贯所有部门，注明统一 token、计费与权限 |
| 沟通 | 图下方单独一条：虾说是两个被 agent 赋能的超级个体之间、或两个智能组织之间的讨论工具，不是组织内部的执行工具 |

编队名称、人数与 agent 数量都是形态示意，图上注明「仅用于说明分工」，不表示真实团队规模。

## 事实与边界

- 示意图下方写明「部门与人数用于说明分工，工具之间尚未自动打通」。
- 没有声称产品已「实现智能组织」，也没有新增效率、准确率、客户数等未经核验的数字。
- 职能描述来自用户提供的示意图与说明，是对现有产品能力的重组表达，未新增产品功能。
- 四个核心工具（犇马、天枢、璇玑、灵犀）与辅助工具（虾说）、底座（归一、万流）按用户定位分层，不再平铺。
- 概念本身来自外部公开报道（2026-11-12 百度世界大会），此处仅借用命名与框架，页面不引用、不署名。
