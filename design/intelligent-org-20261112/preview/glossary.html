两个词：智人 Agentor 与智能组织 AgentOrg

quukk 对两个词的说明：智人（Agentor）是用 agent 做事的人；智能组织（AgentOrg）是智人与 agent 混编成的组织。附与四款工具的对应关系。

智人 Agentor

用 agent 做事的人。不再亲手操作每一步，而是带一支自己的 agent 队伍：判断留给自己，检索、起草、核对、跑代码交给 agent。两个智人之间谈事，双方都带着自己的结论与依据，所以一轮就能对上，不必从头解释背景。

智能组织 AgentOrg

由智人与 agent 混编成的组织。不按固定岗位分层，而按任务临时组队；把执行、信息交换、流程调度与资料存档分开，再用一套统一的身份与额度托住，让协作能按流程跑起来、经验能留下来。
